# Repositório de Teste

Projeto criado para praticar Git e GitHub.

## Objetivo

Este projeto tem como objetivo praticar conceitos básicos de desenvolvimento web e controle de versão utilizando Git e GitHub.

## Tecnologias utilizadas

- HTML
- CSS
- Git
- GitHub

## Conteúdos praticados

Durante o desenvolvimento deste projeto foram praticados:

- Criação e organização de arquivos
- Commits
- Branches
- Pull Requests
- Controle de versões
- Uso do terminal
- Integração entre Git e GitHub

## Estrutura do projeto

O projeto possui os seguintes arquivos principais:

- `index.html` — estrutura da página
- `estilo.css` — estilos da página
- `README.md` — documentação do projeto

## Fluxo de desenvolvimento

As alterações são realizadas em branches separadas da `main`.

Exemplo:

```text
main
  │
  └── cycle_2
        │
        ├── feat: adiciona título ao projeto
        ├── style: ajusta margem da página
        └── docs: adiciona informações ao README
